3. If done correctly you should have this 1SY73MNtzaQHSGGEbm05dedY9_Cpbfw9j
4. Based on the description figure out this is the ending to a google drive link
5. So https://drive.google.com/file/d/1SY73MNtzaQHSGGEbm05dedY9_Cpbfw9j
6. That provides the flag
